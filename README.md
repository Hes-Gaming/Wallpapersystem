1. Add your Wallpaper that you want in the wallpapers folder and make sure it is a mp4 file. 
2. in config.md add the filename with ext to apply it.
3. Optional: with ffmpeg installed (on PATH or next to the exe), a wallpaper larger than the screen or above 8 Mbps is re-encoded once at startup into wallpapers/optimized and reused afterwards.
